One sharp, funny loading-screen tip for stressed developers and AI coding agents, 127 characters:

> Tip: don't hit refresh — the AI is still thinking, you're still waiting, and the loading bar is the only one of us with a plan.

## What it is

A real tip disguised as a joke: when a build stalls, the stressed developer's first instinct is to hit refresh, which only restarts the wait. The line speaks to both sides of the keyboard at once — the human waiting and the AI thinking — and lands the punchline on the loading bar, the only one of the three with a plan. No coffee, no deadline, no compile joke.

## Run it

```sh
python3 main.py
```

This prints the tip and writes it to `/output/entry.txt` (or `output/entry.txt` as a local fallback). `main.py` validates the tip before writing — 1 to 200 characters, a single line, valid UTF-8 — and re-validates the file after writing.
